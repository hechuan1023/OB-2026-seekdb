# 分阶段资源采集与候选回退

基线为 `8ba35e7973cdb681cf80b45bb5fb8c5da5d8e471`，SQL 引擎与 `c13bf4b497d2e150c0053ede9a8205477c584fb1` 一致。本轮针对上次的待确认问题建立设备归属测试和分阶段测试，随后尝试排序表达式延迟与 BIGINT 检查两项改动。两项均未通过性能验收，**SQL 引擎已恢复为基线代码**。

## 本地设备归属

`tests/io_attribution_probe.py` 在独立容器和卷中通过 `stat('/data').st_dev`、mountinfo 和 cgroup `io.stat` 识别数据卷设备为 `8:64`（Docker Desktop Linux 虚拟磁盘上的 ext4）。分别执行 8,388,608 字节同步写入和使用 `posix_fadvise(DONTNEED)` 的受控读取，容器 cgroup 对该设备的写入、读取增量均为 8,388,608 字节，见 `perf-io-attribution-probe.json`。

这验证了本地该次测试的归属，不证明正式平台的设备、物理介质或写回归属相同，也不代表对全部工作负载和后台写回的完整验证。不能用 Docker Desktop 本地结果代替正式统计。

## 测量方法

`tests/perf_attributed.py` 提前生成 SQL；容器 2 CPU、256 MiB、禁用 swap、独立卷；10,000 条 128 维向量、每批 100 条自动提交、1,000 次精确 TopK，过滤和无过滤各一半。两版各三轮并交换顺序再各三轮。测试独立核对每次查询 ID、顺序、距离；完整投影还核对标签和向量。每轮完成指标采集后正常重启，逐条核对全部 10,000 条记录。

写入快照在装载结束采集，查询快照在建索引、全部查询结束后采集，均包括进程启动以来的本地 cgroup 累积值；内部采样进程、`sync` 和其内存也包含在 cgroup 内。没有平台的冷缓存流程，容器退出后没有继续保留 cgroup 跟踪全部后台写回，故这些数值是本机对照而非正式 E、B 或 M。所有基准查询快照设备读字节为 0，不能作为冷读测量证据。

## 结果：排序表达式延迟

| 场景 / 顺序 | 基线写入 | 候选写入 | 基线查询 | 候选查询 |
| --- | ---: | ---: | ---: | ---: |
| 5 值数值投影，基线先 | 2.142 s | 2.122 s | 2.188 s | 2.404 s |
| 相同场景，候选先 | 2.068 s | 2.018 s | 2.273 s | 2.400 s |
| 600 值完整投影，基线先 | 2.064 s | 2.223 s | 4.392 s | 4.446 s |
| 相同场景，候选先 | 1.855 s | 2.075 s | 3.764 s | 4.332 s |

纯数值查询在两种顺序下分别慢约 9.8% 和 5.6%，与上次结果相反。由于在新采集条件下反复出现性能回退，按验收规则撤回该改动。不能据此断言回退一定由代码造成；也不能挑选上次有利结果作为结论。

## 结果：BIGINT 字面值检查

候选将 BIGINT 数字检查从正则改成 `isdecimal()`；除这一处外不改变引擎。两种数值投影顺序中，写入中位数分别为基线 2.107 / 2.248 秒，候选 2.120 / 2.112 秒；两种完整投影顺序为基线 2.011 / 2.039 秒，候选 2.046 / 2.100 秒。没有稳定的端到端写入收益；完整投影查询中位数分别为基线 4.206 / 4.538 秒、候选 4.583 / 4.582 秒。查询逻辑未改，不能排除环境波动，但同样不具备接受该候选的证据，因此撤回。

以上两项在所有实验中，设备 `8:64` 的同步写入计数：5 值负载写入后 8,605,696 字节、查询后 8,609,792 字节；600 值负载分别为 8,622,080、8,626,176 字节；每种镜像每轮相同。写入阶段内存峰值中位数约 26.5～27.3 MiB，查询累计峰值约 37.7～38.7 MiB，含采样器。逐轮时间、两阶段原始计数和重启核验数量分别保存在 `perf-sorter-attributed-*.json` 与 `perf-bigint-attributed-*.json`。

复现示例：构建基线与候选镜像后运行 `python tests/perf_attributed.py --image BASE --compare CANDIDATE --groups 5 --projection numeric --queries 1000 --rounds 3 --output RESULT.json`；交换 `--image` 和 `--compare` 重跑，完整投影使用 `--groups 600 --projection full`。输出路径不能与其他进程共用。

本轮保留测量脚本、真实数据及 BIGINT 符号、Unicode 数字、溢出与非法格式的边界回归；不把两项局部实验包装为性能提升。正式高分版本和参赛分支未被覆盖。

回退后，Linux 容器原生内核下 `python -m unittest discover -v` 共 121 项通过；使用回退后的基线镜像，官方公开协议驱动 20 组通过（`perf-attributed-public.json`）。该验证不代表隐藏正式用例通过。
